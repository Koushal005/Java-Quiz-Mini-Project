# Java Quiz Application

A simple console-based Quiz Application developed using Core Java, Hibernate, and MySQL. This project was built to understand Java fundamentals, object-oriented programming, database integration, and CRUD operations.

## Features

- User Registration & Login
- Attempt Multiple Choice Quiz
- Automatic Score Calculation
- Stores User Details and Results in MySQL
- Hibernate ORM for Database Operations

## Tech Stack

- Java
- Hibernate
- MySQL
- Maven

## Project Structure

```
src/
 ├── Main.java
 ├── User.java
 ├── Question.java
 └── HibernateConnect.java
```

## How to Run

1. Clone the repository.
2. Create a MySQL database.
3. Update the database credentials in `hibernate.cfg.xml`.
4. Build the project using Maven.
5. Run `Main.java`.
